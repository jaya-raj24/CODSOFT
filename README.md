# To-Do List App
This project is developed as part of the CodSoft Android Development Internship.
## Features
- Add new tasks
- Edit existing tasks
- Update tasks
- Delete tasks
- Store data locally using SharedPreferences and Gson
- Automatically load saved tasks when the app is reopened
## Technologies Used
- Java
- Android Studio
- ListView
- SharedPreferences
- Gson
## Project Outcome
This application helps users manage daily tasks efficiently. The task data is stored locally on the device, ensuring that tasks remain available even after closing and reopening the application.
